Actividad para el ramo de Desarrollo de Aplicaciones Moviles! hicimos uso de Kotlin en Android Studio.

el objetivo principal era hacer uso de  composables básicos de layout (Column,Box), la gestión de estado con remember y mutableStateOf, 
la carga de recursos deimagen desde el directorio drawable,
y el uso de modificadores (Modifier) para el
dimensionamiento, alineación y espaciado de los elementos.
